# Кітапхана ақпараттық жүйесі

## Жобаның мақсаты

Кітапханадағы кітаптарды, оқырмандарды,
кітап беру және қайтару процестерін автоматтандыру.

## Негізгі пайдаланушылар

- Оқырман
- Кітапханашы
- Әкімші

## Негізгі функциялар

- Пайдаланушыны тіркеу
- Жүйеге кіру
- Кітап іздеу
- Кітап туралы ақпаратты көру
- Кітапты онлайн брондау
- Кітап беру және қайтару
- Пайдаланушыларды басқару
- Есеп қалыптастыру
